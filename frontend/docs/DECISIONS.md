- Toggle icon: `lucide-react`'s `Moon` (dark theme active) / `Sun` (light theme active), 22px. Chosen over Material Symbols `dark_mode`/`light_mode` and other lucide pairs (`MoonStar`/`SunMedium`, `CloudMoon`/`CloudSun`) after visual comparison — first icon in the header to use lucide-react instead of Material Symbols. (2026-09-02)
- Highlight/brand accent recolored from indigo/violet (`#4648d4`/`#6063ee`/`#6366f1`/`#8b5cf6`/`#c0c1ff`) to emerald green, across `tailwind.config.js`'s `primary` token, `theme.css`'s `--primary*` variables (both unused currently — no component reads them yet), and the hardcoded arbitrary-value colors in `Header.tsx`/`Sidebar.tsx`. Chosen over matching the existing `secondary` green or a darker forest green, after offering both as options. (2026-09-04)

## Chat

- Added a floating AI chat button (`ChatButton.tsx`): fixed to the right edge (`right-0`), icon-only (no label), `BotMessageSquare` (lucide-react, user-picked over `MessageCircle`/`Sparkles`/`Bot`/`MessageSquare`). Styled to match the Sidebar logo badge's brand gradient (dark: `from-[#10b981] to-[#34d399]`, light: `from-[#059669] to-[#10b981]`). `onClick` currently just logs — placeholder until wired to the AI backend. (2026-09-04)
- Chat button reshaped from a floating circle to a half-pill tab flush against the screen's right edge: `rounded-l-full` / `rounded-r-none`, small asymmetric padding (`pl-2.5 pr-3`, widens slightly on hover) so it reads as merged into the edge rather than floating. Icon size kept at 26px — only the surrounding padding was shrunk. (2026-09-04)
- Added `ChatPopup.tsx`, opened by clicking the `ChatButton`: a fixed `bottom-24 right-4` card (`380px` wide, `520px` tall) with a header ("AI Assistant" + close), a scrollable message list, and a text input + send button. User bubbles are solid accent-filled (right-aligned); assistant bubbles are flat neutral pastel (left-aligned) — no gradients, per the existing flat-UI convention. Icons (user-picked over alternatives offered): close `X`, send `SendHorizontal`, copy `Copy` (swaps to `Check` + "Copied" label for 1.5s after click). Sending a message appends a placeholder assistant reply (no AI backend wired yet, same placeholder pattern used elsewhere). The `ChatButton` is hidden while the popup is open (popup has its own close button) to avoid it peeking out from behind the popup's right edge. State (`messages`, `input`) is local/self-contained in `ChatPopup`, not lifted to `App.tsx`. (2026-09-05)
- "Copy" button appears only under the most recently received assistant message (not every message), per the literal ask to copy "the last response". (2026-09-05)
- `ChatPopup` is now vertically draggable: its header (the "AI Assistant" title bar) acts as a drag handle (`cursor-grab`/`cursor-grabbing`, mouse + touch), letting the user slide the whole popup up/down the screen. Position is tracked as a `bottom` pixel offset in local state (not lifted to `App.tsx`), clamped so at least `160px` of the popup stays on-screen when dragged toward the top and it can't go below `8px` from the bottom edge. The popup's `max-height` is derived from that same offset (`calc(100vh - bottom - 16px)`) so it shrinks instead of overflowing off the top of the viewport as it's dragged higher. Per explicit user request, it always reopens at the original default bottom position (`96px`, matching the prior fixed `bottom-24`) regardless of where it was last dragged to — the offset resets via a `useEffect` keyed on `isOpen`, it isn't persisted across opens (unlike `ChatButton`'s drag position, which does persist via `localStorage`). Horizontal position (`right-4`) is unchanged/not draggable. (2026-09-05)
