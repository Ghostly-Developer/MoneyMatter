# Project Context for MoneyMatter

MoneyMatter is a personal finance application focused on import/export, document tracking, investment management, and expense analysis.

## Core Scope
- Financial data import/export from accounting applications using JSON and XML.
- Payslip import and storage.
- Investment entry and tracking: fixed deposits, mutual funds, equities, and other asset types.
- Tracking credit card bills and account statements.
- Document management for retirement accounts such as EPF, NPS, PPF, savings account details, personal IDs, and tax documents.

## User Needs
- A central place to store financial and personal documents.
- The ability to capture multiple types of financial records and categorize them.
- Visibility into spending and investment performance.
- Ways to merge and group expenditures for clearer reporting.

## Functional Features
- Import financial documents and parse structured data.
- Store documents and record metadata for easy retrieval.
- Support bill capture and viewing for recurring expenses like electricity.
- Add tax-related documents such as ITRs and Form 16.
- Provide graphs for investment and expense trends.
- Map expense items into groups and subgroups for better analysis.

## Importance of Context
This file is intended to help developers and agents understand the target application and its expected capabilities. It should be used as a reference when implementing features or reviewing work.
