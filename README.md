# MoneyMatter
## Studio : https://stitch.withgoogle.com/projects/7444899459879889575
## Main Feature
- Import - Export files from Accouting Apps {JSON, xml...}
- Import - Payslip 
- Add investment {Like FD, Mutual Funds, Equity.....}
- Add Credit card bill, Account Statment
### Feature
- Record Document likes Retirement Accounts {EPF, NPS, PPF}, Saving Account Detils..
- Import personal Document and IDs
- Allow save and view Bill {like electricity ....}
- Add Tax ITRs / Form 16...
### Money Analysis
- Graph for Investment
- Credit card investment graph
- Graph for expense {Like monthly group expense}
- View and Map expenditure Items with expenditure groups
- Create expenditure merges{User can add multiple expenditure item in one groups, also subgroup } and final merge expenditure can be added to expenditure group , Example of Expenditure groups can be contruction , Trips...
- Sorting and selection of expenditure
